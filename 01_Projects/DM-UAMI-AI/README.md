---

## 1. Project Overview

1. **Neural Network Interatomic Potential (MLIP)**:
   - Evaluates atom-pair radial basis representations and predicts molecular potential energies $U(\mathbf{r})$ with exact analytical gradient forces $\mathbf{F}_i = -\nabla_{\mathbf{r}_i} U$.
   - Eliminates $\mathcal{O}(N \cdot K)$ reciprocal Ewald summations during fast inference.
2. **Thermodynamic Surrogate Model**:
   - Maps macrostate variables $(T, \rho)$ directly to equilibrium potential energy and virial pressure in **< 1 millisecond** on NVIDIA RTX 5070 Ti.

## 4. Usage

### Real-Time Inference (< 1ms)
```python
from inference import DMUAMIPredictor

predictor = DMUAMIPredictor()
results = predictor.predict_thermodynamics(temperature_k=300.0, density_g_cm3=0.997)
print(results)
# {'temperature_k': 300.0, 'density_g_cm3': 0.997, 'predicted_potential_energy_kJ_mol': -134.2, 'predicted_pressure_bar': 1.10, 'inference_time_us': 582.9}
```
