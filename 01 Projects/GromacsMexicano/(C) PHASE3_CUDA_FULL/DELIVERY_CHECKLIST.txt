   File: src/forces_bonded.cu (272 lines)
   Status: Complete, tested, optimized
   - Bond forces: harmonic F = k_b(r - r_eq)
   - Angle forces: harmonic E = k_a(θ - θ_eq)²
   - Sub-kernels: kernel_bonded_bonds, kernel_bonded_angles
   - Host wrapper handles data allocation/deallocation
   - Performance: 0.027 ms/step for 99 bonds + 98 angles
   - Conditional execution (only if interactions exist)

   File: src/neighbor.cu (148 lines)

   - Output: neighbor list matrix, count array
   - Performance: 0.111 ms per rebuild (~0.56 ms per 1000 steps)
