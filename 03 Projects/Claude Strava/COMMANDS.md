## Tools disponibles (MCP Strava)
Ya está conectado el MCP de Strava en este entorno. Herramientas relevantes:
- `list_activities` — listar actividades recientes
- `get_activity_performance` — rendimiento de una actividad
- `get_activity_streams` — datos crudos de una actividad (potencia, FC, cadencia, etc.)
- `get_athlete_profile` — perfil del atleta
- `get_athlete_zones` — zonas de potencia/FC configuradas
- `get_gear` — equipo/bicis registradas
- `get_training_plan` — plan de entrenamiento (si existe en Strava)
- `eligibility` / `health` — chequeos de la integración
