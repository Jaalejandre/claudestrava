OPTIMIZATIONS IMPLEMENTED (10 Techniques)
═══════════════════════════════════════════════════════════════════════════

 1. ASYNC CUDA STREAMS
    → 3-stream pipeline (compute, H2D transfer, D2H transfer)
    → Enables compute-transfer overlap
    → Expected gain: 1.2-1.5×

 2. PINNED HOST MEMORY
    → cudaMallocHost for DMA-capable buffers
    → Eliminates page faults during transfers
    → Expected gain: 1.1-1.3×

 3. GRID-STRIDE LOOPS
    → Dynamic iteration bounds (idx += gridDim.x * blockDim.x)
    → Full SM utilization (SM% > 80%)
    → Expected gain: 1.3-1.8×

 4. WARP-LEVEL REDUCTIONS
    → __shfl_xor_sync for shuffle-based reductions
    → Eliminates atomic contention (30× reduction in atomics)
    → Expected gain: 1.1-1.4×

 5. SHARED MEMORY CACHING
    → 1KB per block for warp-tile data
    → Reduces global memory round-trips
    → Expected gain: 1.2-1.6×

 6. MEMORY COALESCING (SoA Layout)
    → Structure-of-Arrays (x[], y[], z[]) instead of float3 structs
    → Perfect memory coalescing (128 threads → 128 consecutive addresses)
    → Expected gain: 1.1-1.3×

 7. KERNEL PIPELINING
    → Frame N compute while N+1 transfers
    → Maintains continuous GPU/host/memory bus saturation
    → Expected gain: 3× latency reduction

 8. REGISTER OPTIMIZATION
    → maxrregcount=128 to maximize occupancy
    → Balances register usage vs. SM occupancy
    → Expected gain: 1.05-1.15×

 9. FAST MATH MODE
    → -use_fast_math for relaxed FP precision
    → Optimized sqrt(), exp(), sin(), cos()
    → Expected gain: 1.05-1.10×

10. LOOP UNROLLING
    → Compiler-driven unrolling (-funroll-loops)
    → Reduced control flow overhead
    → Expected gain: 1.05-1.10×
