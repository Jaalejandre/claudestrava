## JUSTIFICACIÓN

**¿Por qué nomenclatura?**

1. **Identidad SatanZote:** Sistema tiene nombre, equipos deben reflejarlo
2. **Claridad operacional:** Nombre ≠ número, comunicación menos confusa
3. **Branding interno:** Cultura + reconocimiento
4. **Escalabilidad:** E35, E36 automáticamente siguen patrón
5. **Comunicación externa:** Si monetizas (marketing E34), profesional

**Ejemplo confusión actual:**
```
"E33 coordina con E25 sobre E34"
  → ¿Qué son esos números?

"Zeros-Contador coordina con Zeros-Explorador sobre Zeros-Vendedor"
  → Inmediatamente claro qué hace cada uno
```
