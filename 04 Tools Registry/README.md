# Tools Registry

Registro persistente de herramientas externas evaluadas para adopción en el ecosistema SatanZote.

**Estructura**: un archivo por herramienta, con metadatos completos.

**Formato de entrada**:
| Campo | Descripción |
|-------|-------------|
| Nombre | Nombre de la herramienta |
| URL | Repositorio/web oficial |
| Propósito | Qué problema resuelve |
| Decisión | Sí / No / Parcialmente |
| Razón | Justificación detallada |
| Casos de Uso | Escenarios donde aplica |
| Fecha | Fecha de evaluación |
