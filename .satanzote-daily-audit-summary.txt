## HOW IT WORKS (Every Morning at 06:00)

[06:00] Cron triggers → Hermes Orchestrator loads
         ↓
[06:02] Infrastructure Auditor checks:
         • Hermes running?
         • Proxmox responding?
         • Vault synced?
         ↓ (returns JSON: OK|ERROR)
         
[06:05] Project Monitor checks:
         • Phase 4: commits? builds?
         • L'Étape: Strava synced?
         • Prototypes: endpoints alive?
         ↓ (returns JSON: OK|CHANGED|ERROR)
         
[06:10] Documentation Writer creates report:
         • If all OK: lightweight summary
         • If CHANGED: detailed changelog
         • If ERROR: diagnostic + recovery steps
         ↓ (saves to vault, git commit)
         
[06:12] Orchestrator sends Telegram alert
         • José wakes up to summary
         
[06:15] Done. Total: 12-30 min (depending on findings)
